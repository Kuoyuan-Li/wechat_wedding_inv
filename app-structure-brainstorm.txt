请帮我实现一个微信婚礼邀请函小程序。你需要同时以专业 UI/UX 设计师和小程序工程师的角度完成设计与实现，重点关注视觉审美、移动端交互体验、页面节奏、组件间距、留白、字体层级和代码结构。

项目目标：
制作一个单页式 SPA 婚礼邀请函小程序。用户通过上下滑动屏幕切换不同页面，每一屏占满整个手机视口。整体体验应当优雅、浪漫、精致，但不要过度复杂或堆叠装饰。

页面结构：
小程序共有 4 个页面，按顺序为：

1. Landing Page
2. 故事 / 照片回忆页
3. 婚礼详情页
4. 宾客信息页

全局交互要求：
- 使用纵向滑动切换页面。
- 每一屏应占满完整视口高度。
- 除最后一页外，每一页底部都需要显示下一页的标题提示和向下箭头，引导用户继续下滑。
- 页面切换应自然顺滑，适合微信小程序移动端体验。
- UI 需要适配常见手机屏幕尺寸，避免文字、按钮、图片或表单元素重叠。

页面 1：Landing Page
- 第一屏为完整的封面图。
- 图片路径为：`miniprogram/assets/photo1.jpg`
- 该图片已经由专业软件设计完成，包含封面所需的全部视觉元素。
- 此页面不需要额外标题、按钮、文字或装饰组件。
- 图片应铺满整个屏幕，保持良好裁切与显示效果。
- 页面底部仍需显示进入下一页的提示，例如下一页标题和向下箭头，但要尽量低调，不破坏封面图视觉。

页面 2：照片回忆页 / Image Carousel
- 该页用于展示新人在一起的旅行、日常生活、毕业、求婚等重要回忆。
- 页面需要包含一个合适的中文标题，但标题不能使用“我们的故事”。
- 请根据页面内容自行设计一个更有质感、更自然的标题，例如偏浪漫、纪念感、生活感的表达。
- 页面主体应使用 Image Carousel / 横向轮播交互。
- 用户通过左右水平滑动切换不同的照片与文字组合。
- 每一页轮播项包含：
  - 一张照片
  - 一小段说明文字，用于描述该段回忆
- Carousel 需要有清晰的当前进度提示，例如圆点 indicator、页码，或符合整体设计风格的进度元素。
- Carousel 的左右滑动不应影响整个 SPA 的上下滑动体验；需要注意纵向页面切换和横向图片轮播之间的手势体验。
- 当前照片和文案内容可以先使用 placeholder，但代码结构要方便后续替换为真实图片和真实文案。
- 图片展示需要注意比例、裁切、留白和文字可读性。
- 整体布局应适合移动端，画面要有婚礼邀请函的精致感和纪念感，不要显得像普通图片列表。

页面 3：婚礼详情页
- 页面标题为：`婚礼详情`
- 显示以下婚礼信息：
  - 日期：2026年11月15日 星期日
  - 时间：上午10:30 迎宾
  - 地点：天津市东凯悦酒店 二楼宴会厅1
- 地点信息下方需要有一个“导航详情”入口。
- “导航详情”应包含地图 icon 和文字。
- 点击后应跳转或打开地图导航相关能力。请根据微信小程序最佳实践实现或预留清晰的实现方式。
- 该页视觉上应清晰、庄重、易读，可以突出日期、时间和地点的层级。

页面 4：宾客信息页
- 页面标题为：`您的信息`
- 页面包含一个表单，用于收集：
  - 姓名
  - 宾客数量
- 宾客数量使用 dropdown / picker 选择器。
- 可选项为：`1`、`2`、`3`、`4`、`5`、`更多`
- 页面包含一个提交按钮。
- 表单需要有良好的输入反馈、间距和移动端可点击区域。

宾客信件互动功能：
- 在宾客信息页中加入一个互动功能。
- 项目中会有一个类似 dictionary / key-value map 的数据结构，用于根据宾客姓名查询对应信件。
- 数据结构要求：
  - key 可以是单个姓名，也可以是一组姓名。
  - 多个姓名可以映射到同一封信。
  - value 是新郎 / 新娘写给该宾客的一封信。
- 当用户填写姓名并提交后：
  - 如果姓名命中该数据结构，则自动弹出 modal dialog。
  - modal 中展示“新郎/新娘写给你的一封信”。
  - 当前信件内容可以先使用 placeholder。
  - 如果姓名未命中，可以给出温和提示，例如“信息已收到”或“不管是否有专属信件，都期待与你相见”。
- modal 的视觉设计需要温柔、正式、有婚礼邀请函质感。
- 后续需要方便我替换和维护姓名与信件内容。
